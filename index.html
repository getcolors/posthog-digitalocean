PostHog on DigitalOcean

A single-node PostHog product analytics deployment at posthog.bigconfig.online.

Architecture

Cloudflare and Caddy expose HTTPS. The Django web service, Celery worker, PostgreSQL 17, ClickHouse 24.8, and Redis 7.2 remain private on one Amsterdam Droplet. Schema migrations run against the datastores before the application containers start.

Recovery

Persistent disk survives restarts, and a daily pg_dump plus a native ClickHouse BACKUP archive to R2 support disaster recovery. This single-node design is not highly available.
